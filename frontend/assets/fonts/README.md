# Page heading font

LXGW WenKai Regular: https://github.com/lxgw/LxgwWenKai

Licensed under SIL OFL 1.1; see OFL-WenKai.txt. Recompiled as WOFF2 with Latin and characters from current page headings and integration.js, without changing glyph designs. Used only for page headings; body and controls keep the application's sans-serif stack. Missing characters use the serif fallback. Rebuild the subset when new heading characters are introduced.
